# RevenueOps 360

**Sales and revenue analytics | Snowflake · dbt Core · SQL · Python · Streamlit**

## Overview

RevenueOps 360 brings customer, sales opportunity, and payment data together to make sales performance easier to understand. It shows how raw data can be organized into reliable metrics and a simple, interactive dashboard.

## What I Built

- Loaded and organized sales and payment data in **Snowflake**.
- Used **dbt and SQL** to clean the data, build related tables, and create reporting summaries.
- Added **data quality and reconciliation tests** to check records and totals.
- Built a **Streamlit dashboard** using exports from the reporting tables.

## Outcomes and Dashboard

The dashboard gives an overview of **won deal value, cash collected, open pipeline, and total sales opportunities**. It also compares sales representatives by deal value and pipeline, with a closer look at each person's win rate and opportunities.

The result is a clear, reusable reporting workflow that turns separate sales and payment records into consistent business metrics.

## Data Flow

`Sales & payment data → Snowflake → dbt models and tests → Reporting tables → Streamlit dashboard`
